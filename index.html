Release Pipeline

+
04 · CI/CD · GitOps

From git push to a validated release

Every OpenObserve and observability change follows the same repeatable path to production.

  • Work developed in Git and pushed to GitLab
  • Jenkins builds the latest version and stores the artifact in Nexus
  • ArgoCD syncs the new build to the cluster with Helm
  • The full application flow is validated before sign-off
